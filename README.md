# Developer Notes

A route-based React library for practical developer references. It brings Algorithms Core Notes, Architecture & Clean Code Core Notes, Apache Derby Notes, Android Notes, Angular Notes, ASP.NET Core Notes, Backend Engineering Core Notes, C Core Notes, C and C++ Study Notes, Chakra UI Study Notes, CodeIgniter 4 Study Notes, DataTables Study Notes, DevOps and Cloud Core Notes, Docker Study Notes, Express.js Study Notes, FastAPI Study Notes, FileZilla Notes, Firebase Notes, Firestore Notes, JavaScript Notes, Laravel Notes, Linux Notes, Material UI Notes, and MongoDB Notes together, with each collection and its chapters kept locally in the app.

## Features

- Algorithms Core Notes with ten focused sections
- Architecture & Clean Code Core Notes with 27 original topic pages
- Apache Derby Notes with 17 chapters, a complete code-samples appendix, and Q&A
- Android Notes with all 17 original Markdown chapters
- ASP.NET Core Notes with 19 chapters, a code-samples appendix, and Q&A
- JavaScript Notes with 16 original chapters, code recipes, and Q&A
- Angular Notes with 16 original chapters, code samples, and Q&A
- C Core Notes with a focused 18-section interactive programming guide
- C and C++ Study Notes with all 19 original Markdown chapters
- Chakra UI Study Notes with all 15 original Markdown chapters
- CodeIgniter 4 Study Notes with all 18 original Markdown chapters
- DataTables Study Notes with all 18 original Markdown chapters
- DevOps and Cloud Core Notes with 17 interactive topic routes
- Docker Study Notes with 16 core chapters, code samples, and Q&A
- Express.js Study Notes with the complete original Markdown chapters
- FastAPI Study Notes with the complete original Markdown chapters
- FileZilla Study Notes with all 18 original Markdown chapters
- Firebase Study Notes with all 18 original Markdown chapters
- Firestore Study Notes with all 18 original Markdown chapters
- Laravel Study Notes with 16 chapters, code samples, and Q&A
- Linux Study Notes with 16 practical chapters, command examples, and Q&A
- Material UI Study Notes with 18 chapters, practical component examples, and Q&A
- MongoDB Notes with 16 core chapters, a complete code-samples appendix, and Q&A
- Local chapter content, linked navigation, and original repository links
- Responsive layouts, route loading spinner, and smooth scroll-to-top

## Tech stack

React, Vite, React Router, React Markdown, remark-gfm, styled-components, and React Icons.

## Run locally

Use Node.js 22.13 or newer in the 22.x line, or Node.js 24 or newer.

```bash
npm ci
npm run dev
```

## Deploy

```bash
npm run deploy
```

The site is configured for GitHub Pages at [a2rp.github.io/notes](https://a2rp.github.io/notes/). The build creates a `404.html` fallback so direct chapter routes continue to work.
