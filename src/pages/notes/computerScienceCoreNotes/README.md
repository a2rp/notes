# Computer Science Core Notes

A broad study guide for the foundations and systems that shape modern software. The chapters explain operating systems, networks, databases, system design, software engineering, compilers, distributed and parallel computing, computation theory, cryptography, security, and cloud services.

## Study path

Start with the operating system and network foundations, then review databases and system design. Continue through software construction, compilers, distributed systems, and parallel computing. Finish with formal computation, cryptography, security, and cloud concepts.

Use the chapter list to focus on one subject at a time. Standards, tools, and cloud services evolve, so confirm current details in the relevant official documentation when applying a concept.
