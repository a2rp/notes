# HTML Core Notes

The original interactive HTML revision guide, preserved as a route in the Notes collection.

- Route: `/notes/html-core-notes`
- Original source repository: `a2rp/html-core-notes` (retired after migration)
- Coverage: document foundations, semantics, text, links, media, tables, forms, metadata, accessibility, performance, SEO, and security.

The app source and topic content are kept in `content/`. Its theme is scoped to this route so it does not change the Notes site theme.
