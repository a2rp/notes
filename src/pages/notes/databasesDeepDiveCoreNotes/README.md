# Databases Deep Dive Core Notes

An interactive study guide for SQL and MongoDB engineering, including aggregation, index strategy, schema design, joins, transactions, replication, scaling, and sharding.

The complete original React app, assets, setup files, and README are preserved in `source/`. The Notes route loads its original study interface as a standalone page in the collection.

## Topics

- SQL, joins, and subqueries
- MongoDB and aggregation
- Index strategy and schema design
- Transactions, replication, and sharding
- Database scaling and architecture
