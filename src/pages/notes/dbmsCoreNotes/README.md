# DBMS Core Notes

An interactive revision guide covering database fundamentals, data models, SQL, constraints, normalization, transactions, indexing, query optimization, NoSQL, security, and recovery.

The complete original React app source, assets, setup files, and documentation are preserved in `source/`. The Notes route renders the original study interface inside the notes collection.

## Topics

- Relational and entity-relationship models
- SQL fundamentals, querying, joins, and constraints
- Normalization, transactions, and concurrency
- Indexing, storage, query optimization, and distributed databases
- Security, backup, and recovery
