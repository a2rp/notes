# C++ Core Notes

The original interactive C++ study guide, preserved as a route in the Notes collection.

- Route: `/notes/cpp-core-notes`
- Original source repository: `a2rp/cpp-core-notes` (retired after migration)
- Content: overview plus 19 expandable learning topics, including fundamentals, types, operators, control flow, functions, pointers, OOP, templates, STL, modern C++, concurrency, build systems, and pitfalls.

The app source and topic content are kept in `content/`. Its theme is scoped to this route so it does not change the Notes site theme.
