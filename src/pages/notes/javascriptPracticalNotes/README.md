# JavaScript: Practical Notes

**Collection source:** [Notes repository](https://github.com/a2rp/notes/tree/main/src/pages/notes/javascriptPracticalNotes)

These are my personal learning notes, shaped by what I study and practice. Here, I am gathering JavaScript concepts into a clear, practical guide that I can revisit and share.

The course roadmap covers the JavaScript language, browser programming, common web APIs, Node.js, tooling, testing, security, performance, and practical projects. It is organized as a step-by-step reference from first principles through advanced topics.
