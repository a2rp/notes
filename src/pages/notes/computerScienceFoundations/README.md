# Computer Science Foundations

Beginner-friendly lessons that explain foundational ideas across operating systems, networking, databases, compilers, and web communication. Each chapter connects key terms to concrete examples and shows how related parts of a computer system work together.

## Study path

Begin with processes, memory, scheduling, and file systems. Continue through network layers, DNS, HTTP, TLS, TCP, and WebSockets. Then study database transactions and query performance, followed by compiler stages, syntax trees, transpilation, and load balancing.

Use the chapter list to revisit one concept at a time. Version-specific implementation details can change, so verify them with current documentation when applying them in a project.
