# Data Structures Core Notes

An interactive revision guide for data structures and algorithmic thinking, covering complexity, linear structures, hash tables, trees, graphs, and practical patterns.

The original React app source, setup files, and project documentation are preserved in `source/`. The Notes route loads that app with its own study navigation and theme controls.

## Topics

- Foundations and complexity
- Linear data structures and hash tables
- Trees, graphs, and advanced structures
- Algorithmic patterns and complexity review

## Source

The complete original project is in `source/`, including its README, license, Vite configuration, assets, and all 45 tracked project files.
